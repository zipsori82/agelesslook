1. 서비스 개요

에이지리스 룩(이하 "운영자")은 운영자가 직접 제작한 패션 코디 영상·사진 콘텐츠를 운영자 소유의 소셜 미디어 계정(YouTube, Instagram, Threads, TikTok, Pinterest 등)에 예약·게시하기 위한 자체 도구(이하 "서비스")를 운영합니다. 서비스는 운영자 본인의 계정에만 사용되며 제3자에게 제공되지 않습니다.

2. 이용 자격

서비스는 운영자와 운영자가 승인한 담당자만 이용합니다. 일반 사용자 가입은 받지 않습니다.

3. 콘텐츠

  • 게시되는 영상·사진 속 인물은 AI로 생성한 가상 모델이며, 의류는 실제 판매 상품입니다. 이 사실은 각 게시물에 표기합니다.
  • 게시물에는 쿠팡 파트너스 등 제휴 링크가 포함될 수 있으며, 그 사실을 게시물 첫 줄에 고지합니다.
  • 콘텐츠의 저작권은 운영자에게 있습니다. 각 플랫폼에 게시된 콘텐츠는 해당 플랫폼의 약관을 따릅니다.

4. 플랫폼 API 이용

서비스는 각 플랫폼이 공식 제공하는 API(예: TikTok Content Posting API, Instagram API, Threads API, YouTube Data API)를 통해서만 게시합니다. 운영자는 각 플랫폼의 개발자 약관과 커뮤니티 가이드라인을 준수합니다.

5. 책임의 한계

서비스는 "있는 그대로" 제공됩니다. 플랫폼 측 장애, API 정책 변경 등으로 게시가 지연·실패할 수 있으며, 운영자는 이에 대해 제3자에게 책임을 지지 않습니다.

6. 약관 변경

약관은 이 페이지에서 갱신하며, 변경 시 시행일을 함께 표기합니다.
